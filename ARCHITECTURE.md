# ASTREX — Архитектура проекта

## 1. Продукт

**ASTREX** — интерактивная образовательная платформа по трейдингу и криптовалютам.
Позиционирование: «Duolingo для трейдинга» — структурированный путь от новичка до
продвинутого трейдера через уроки, задания, тесты, геймификацию и практику на
виртуальном рынке.

**Проблема, которую решаем:** избыток хаотичной, разрозненной и часто недостоверной
информации о трейдинге в интернете. ASTREX даёт единый структурированный путь обучения.

### Ключевые механики MVP

1. **Learning Path** — курсы, разбитые на модули и уроки, выстроенные в дерево/путь
   (как в Duolingo), с блокировкой последующих уроков до прохождения предыдущих.
2. **Уроки** — теория (текст/медиа) + интерактивные элементы.
3. **Задания и тесты** — quiz (single/multiple choice, drag-order, true/false),
   практические задания по анализу графиков.
4. **Геймификация** — XP, уровни, streak (серия дней подряд), достижения (achievements),
   сердца/попытки (опционально в след. итерации).
5. **Виртуальный рынок (paper trading)** — симулятор с виртуальным балансом, открытие
   позиций (long/short) на исторических/симулированных данных, P&L.
6. **Анализ графиков** — встроенный чарт (lightweight-charts, движок TradingView) для
   практики построения уровней, трендовых линий и т.п.
7. **AI-помощник** — чат-ассистент, объясняющий термины, разбирающий ошибки в тестах,
   дающий обратную связь по сделкам на вирт. рынке.

## 2. Технологический стек

| Слой | Технология | Причина |
|---|---|---|
| Frontend/SSR | Next.js 16 (App Router) + React 19 + TypeScript | Один деплой на Vercel, SSR/RSC, файловая маршрутизация |
| Стили | Tailwind CSS v4 | Быстрая точная реализация минималистичного дизайна |
| UI-примитивы | Кастомные компоненты (без тяжёлых UI-китов) | Полный контроль над премиальным видом |
| Анимации | Framer Motion (точечно, минимально) | По ТЗ — «минимальные анимации» |
| Графики | lightweight-charts (TradingView) | Тот же движок, что и у TradingView — консистентный UX |
| Состояние клиента | Zustand | Лёгкий стор для XP/прогресса на клиенте без boilerplate Redux |
| ORM / БД | Prisma + PostgreSQL (dev: SQLite) | Типобезопасность, удобные миграции, лёгкий старт локально |
| Аутентификация | Auth.js (next-auth v5) — credentials + OAuth (Google) | Нативная интеграция с App Router, JWT-сессии |
| Валидация | Zod | Единая схема валидации на клиенте и сервере |
| Пароли | bcryptjs | Хеширование паролей credentials-провайдера |
| Деплой | Vercel | Явное требование продукта |

## 4. Модель данных (сущности верхнего уровня)

- **User** — аккаунт, XP, уровень, streak, дата последней активности.
- **Course** — курс (например, «Основы трейдинга»), порядок, уровень сложности.
- **Module** — раздел внутри курса.
- **Lesson** — урок (теория + контент JSON), принадлежит модулю, имеет порядок и
  требование к предыдущему уроку (для блокировки пути).
- **Question** — вопрос теста/задания, привязан к уроку, тип (choice/multiple/order).
- **UserLessonProgress** — статус прохождения урока пользователем (locked/available/
  completed), заработанный XP.
- **Achievement** / **UserAchievement** — достижения и их получение пользователем.
- **VirtualPortfolio** — виртуальный баланс пользователя для paper trading.
- **VirtualTrade** — сделка (инструмент, направление, объём, цена входа/выхода, P&L).

Полная схема — см. `prisma/schema.prisma`.

## 5. Дизайн-система

См. `src/app/globals.css` и `src/components/brand/`. Кратко:

- Фон: чистый чёрный (`#000000` / `#050505`) с эффектом глубокого космоса
  (статичное поле редких звёзд, лёгкий параллакс на движение мыши — минимально).
- Типографика: геометричный sans-serif (Geist из коробки Next.js) для текста;
  для wordmark-логотипа — увеличенный трекинг (letter-spacing) и заглавные буквы.
- Цвета: чёрный/белый — основа; зелёный (`#00D97E`-подобный) — рост/успех;
  красный (`#FF4757`-подобный) — падение/риск. Никаких лишних акцентных цветов.
- Компоненты: плоские тонкие обводки (1px, полупрозрачный белый), никаких
  «дешёвых» градиентов и теней — только тонкий glow на активных элементах.

## 6. Этапы разработки (roadmap)

1. ✅ Скаффолдинг Next.js + Tailwind + TS.
2. ⏳ Дизайн-система: шрифты, цвета, звёздный фон, SVG-логотипы.
3. ⏳ Prisma-схема + подключение БД.
4. ⏳ Аутентификация (email/password + Google OAuth).
5. ⏳ Лендинг-страница (маркетинг).
6. ⏳ Приватная зона: layout с sidebar/topbar, XP/streak.
7. ⏳ Learning path: курсы → модули → уроки (с demo-контентом).
8. ⏳ Прохождение урока: теория + тест + начисление XP.
9. ⏳ Виртуальный рынок: портфель, открытие/закрытие сделок.
10. ⏳ Модуль анализа графиков (lightweight-charts).
11. ⏳ AI-помощник (чат, интеграция с LLM API).
12. ⏳ Полировка, доступность, деплой на Vercel.

Каждый этап проверяется сборкой (`npm run build`) и вручную в браузере перед
переходом к следующему.
